## Things the table does not show

* **Google ML Kit** (the on-device text reader behind `google_mlkit_text_recognition`)
  is a native SDK under Google's ML Kit terms, not MIT. It runs on the device and
  needs no network for recognition. The app lists third-party licences in
  Settings, About, Open-source licenses.
* **Fonts:** Fraunces and Inter, both SIL Open Font License 1.1; the licence texts
  ship in `assets/licenses/` and are shown in the same licences screen.
* **Open Library** data is public domain / CC0 for bibliographic records; cover
  images keep their own rights. The app only displays them.

Nothing in the list is copyleft in a way that affects distributing the app.
